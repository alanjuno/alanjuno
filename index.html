Carrito Controlado por Bluetooth

Desarrollo de un carrito robot controlado de forma inalámbrica mediante Bluetooth utilizando Arduino.

Para el control del carrito desarrollé una aplicación móvil utilizando MIT App Inventor, permitiendo enviar comandos desde el celular para controlar el movimiento del vehículo.

La aplicación permite controlar los movimientos del carrito mediante diferentes botones, enviando comandos a través de Bluetooth hacia el módulo conectado al Arduino.

  • Control de movimiento hacia adelante y atrás
  • Giro hacia izquierda y derecha
  • Control inalámbrico mediante Bluetooth
  • Comunicación entre aplicación móvil y Arduino
Arduino C++ Bluetooth MIT App Inventor Electrónica
